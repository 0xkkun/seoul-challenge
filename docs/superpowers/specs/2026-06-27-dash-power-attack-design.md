# Dash Power Attack Design

## Goal

대시 중 또는 대시 직후 공격 입력을 보상해 일반 근접보다 강한 "대시 강공격"을 발동한다. 모바일 입력 오차를 감안해 대시 종료 후 0.15초까지 강공격 창을 유지한다.

## Behavior

- `emergency_dodge`가 시작되면 강공격 창이 열린다.
- 강공격 창은 대시가 진행 중이거나 대시 종료 후 `dash_power_attack_grace_time` 안이면 활성이다.
- 강공격으로 근접 공격을 1회 사용하면 창은 즉시 닫힌다.
- 강공격은 기존 맨손/야구배트 계약을 재사용한다.
- 기본값은 피해 +1, 사거리 1.15배, 배트 넉백 1.5배다.
- 원거리 야구공 모드에서는 강공격을 적용하지 않는다.

## Visuals

기존 `MeleeSwing`은 그대로 사용하고, 새 `PowerImpact` `Polygon2D`를 플레이어 씬에 추가한다. 강공격 시 실제 강화 범위에 맞춘 부채꼴 폴리곤을 더 밝은 색으로 짧게 표시해 일반 공격과 구분한다.

## Testing

- 순수 판정 함수로 강공격 창 활성/비활성 조건을 테스트한다.
- `_attack_melee()` 호출 전 테스트 헬퍼로 강공격 창을 열고, 피해 증가/창 소비를 검증한다.
- 배트 장착 상태에서는 강화 넉백이 일반 배트보다 커지는지 검증한다.
- 플레이어 씬에 `PowerImpact` 노드가 존재하고 기본 비표시 상태인지 검증한다.

## Out Of Scope

- 새 아이템이나 스킬 추가
- 적 상태이상 추가
- 외부 아트 리소스 제작
