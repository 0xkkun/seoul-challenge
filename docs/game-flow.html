방과후 요괴뎐

궁(宮)에 갇힌 하루 · After-School Yokai Tale
헐린 옛 궁궐 터 위에 선 학교. 낮엔 평범한 여고생으로 학교를 조사해 반 친구(동아리원) 중 누가 요괴인지 추리하고, 밤엔 같은 공간이 되비친 궁궐에서 요괴를 정화한다. 틀리면 하루가 되감기지만 단서·도감·동아리는 남는다 — 갇힌 하루를 풀어야 탈출.

핵심 시스템

🔍 추리 — 도감 특징 매칭

요괴 = tell 2~3개의 조합. 용의자는 red herring으로 일부 tell이 겹침 → 진짜만 풀셋을 충족. 충분히 모아야 1명으로 좁혀짐.

🎒 동아리 — 동료 해금

용의자 = 동아리원. 정화 → 친구 구출 → 동아리 해금:

정화 도구(약점 카운터) 낮 버프(+조사 등) 조력자 패시브
  • 선형 체인: 이전 도구가 다음 요괴의 열쇠
  • 구출한 친구들이 모여 → '방과후 궁궐 클럽' (제목의 의미)

🔁 타임루프 — 반복

  • 오답/패배 = 되감김 (디제틱: 의식 실패)
  • 누적: 단서 · 도감 · 동아리 · 도구
  • 리셋: 그날의 조사 진행도
  • 막힘 없음 — 선형 해금이 보장

🏯 고궁 — 한 장소, 두 층위

  • 학교는 헐린 옛 궁궐 터 위에 섰다
  • 밤 = 같은 공간이 궁궐로 리스킨
  • 연결: 전환 연출 + 랜드마크 거울링 (교실문↔전각문, 사물함↔석물)
  • "뜬금없이 고궁 감" 없음 — 이동이 아닌 변형
