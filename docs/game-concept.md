# 방과후 요괴뎐 — 게임 컨셉 (GDD)

> 서울 인디게임 챌린지 출품작 · Godot 4.6.3 · 16비트 픽셀아트
> 탑다운 로그라이크 트윈스틱 슈터 × 낮밤 학교 허브 · 서울 학교/고궁 반복 정화

## 감성 코어

**친구와 쌓은 기억을 들고, 밤의 궁에 갇힌 그 애를 구하러 간다.**

무기는 판타지 퇴마구가 아니라 학교의 기억이다 — "비 오는 날 빌린 우산", "마지막 시즌의 배트", "이름이 지워진 학생증". 낮에 쌓은 관계가 밤의 전투력이 되고, 가장 친한 친구가 요괴가 되어 보스로 나타난다.

## 하나의 게임, 두 개의 시간

| | 낮 — 학교 허브 | 밤 — 경복궁 런 |
|---|---|---|
| 시점 | 사이드뷰 | 탑다운 |
| 활동 | 스토리 대화, 상호작용으로 무기 해금 | 트윈스틱 슈팅, 정화·구출·탈출 |
| 전투 | 없음 (스토리/상호작용) | 로그라이크 런 |

## 코어 루프

```
낮(학교 허브) ─ 대화로 스토리·무기 해금
   ↓ 복도 끝 출구
야간 준비 ─ 사물함에서 기억 무기 정비
   ↓ 지도 선택
밤(경복궁 런) ─ 고정 전투방 3~5개 돌파
   ↓
정화·구출·탈출 ─ 친구 정화 + 학생 구출 + 보스 처치
   ↺ 성공/사망 → 학교로 귀환, 해금은 유지된 채 재도전 = 반복
```

**낮에 만든 기억으로, 밤의 궁에서 친구를 구한다.**

## 낮 — 학교 허브 (사이드뷰)

복도를 이동 → 동아리실 문으로 들어가 대화 → 무기/아이템 해금. 전투가 없는 스토리·상호작용 구간. 복도 외곽 끝은 밤으로 나가기 전의 야간 준비 단계로 이어진다.
- 동아리실 입장 · 대화 3단계
- 무기/아이템 해금
- 게시판에서 다음 궁 단서
- 복도 끝 출구 → 사물함 정비

## 야간 준비 — 사물함 정비

낮 허브와 밤 런 사이의 완충 단계. 학교 복도 끝 사물함에서 들고 갈 기억 무기를 고르고, 지도 버튼으로 별도 스테이지 선택 화면을 연다. 정비 화면 안에는 체크리스트나 큰 지도 패널을 두지 않는다.
- 복도로 돌아가기
- 기억 무기 선택(낡은 야구공 · 금 간 알루미늄 배트)
- 지도 선택 화면 열기

## 밤 — 두 겹의 맵

1. **바깥 (스테이지 선택)** — 다키스트 던전풍 영지 지도. "오늘 밤 어느 궁?" 한강(허브)에서 출발해 경복궁 정화. 창덕궁·덕수궁·종묘는 잠금(포스트잼). 지도는 안 C(수직 상승) 1순위.
2. **안 (런 진행)** — 아이작풍 방 미니맵. 상점방 위치는 표시, 보스방은 숨김(?). 방을 비우면 문이 열려 다음 방으로. MVP = 고정 3~5방, 절차 생성은 포스트잼.

## 재화 두 종류 (뉴비 컷 방지)

| 인게임 재화 | 영구 재화 |
|---|---|
| 이번 밤 한정, 런 끝나면 소멸 | 계속 쌓임, 죽어도 유지 |
| 상점에서 소모 | 방 클리어 +1 / 보스 +N |
| 적·방 클리어로 획득 | 학교의 영구 강화·해금에 사용 |

초보가 죽어도 영구 재화는 남는다 → 실패가 처벌이 아니라 성장. 이탈 방지.

## 대화 → 해금

복잡한 호감도 대신 **대화 3단계**. 단계가 오를 때마다 친구의 기억이 무기로 풀린다. 야구부가 기준 템플릿.
- STAGE 1 첫 만남 → 낡은 야구공
- STAGE 2 훈련 후 → 금 간 알루미늄 배트
- STAGE 3 정화 후 → 확장 무기

각 무기엔 한 줄 '기억' 플레이버 텍스트 = 게임의 맛.

## 로드아웃 — 3층 구조

| 반입 무기 | 맵 아이템 | 특수 스킬 |
|---|---|---|
| 학교에서 해금, 영구 소유 | 런 안/상점에서 확보, 런 한정 | 맵 기반, 횟수 제한, swap |

## 구출 · 정화 · 보스

궁 안의 셋 — **구할 학생, 정화할 친구(중간보스), 부술 보스(별개)**.
- 납치 학생: 방마다 랜덤 스폰, 풀어주면 구출 보상
- 요괴화된 친구: 기절 → 정화 (가장 친한 그 애)
- 최종 보스: 친구와 무관, 처치해야 탈출

## 스코프 — 48h MVP 하드 스코프

**넣는 것** (루프를 이해시키는 최소 단위)
- 학교 허브 1화면 · 야구부 주장 NPC(대화 3상태)
- 무기 2개 (야구공 · 배트) · 경복궁풍 방 3~5개
- 잡몹 2종 + 보스 1종 · 낮↔밤↔귀환 루프 + HUD

**미루는 것** (재미 검증 전 리스크)
- 절차적 방 생성 · 상점 · 보물방 · 미니맵 렌더
- 친밀도 MAX · 동아리 3개 확장 · 일일 도전/리더보드
- 다른 궁 3개 (창덕/덕수/종묘)

## 개발 분담 (8세션 · 페어 운영)

밤씬을 먼저 공략한다. 충돌 차단을 위해 **씬 1개 = 오너 1명**, `project.godot`·`event_bus.gd`는 단일 소유.

| 트랙 | 담당 |
|---|---|
| 전투방 · 밤씬 셸 | 동료 트랙 |
| 방 구성 알고리즘(전투방 제외) + 이벤트방 | 우리 트랙 (#1~#4) |

우리 트랙 이슈 (마일스톤: MVP 경복궁 런):
- #1 `Room` 베이스 계약 & 문/전이 상태머신 (+ EventBus 시그널·팔레트 단독 소유)
- #2 RoomManager + 방 그래프 구성 알고리즘 (RoomDef/RoomLayout)
- #3 EventRoom 베이스 + 구출방(납치 학생)
- #4 시작방·보스방 셸·보물방 스텁 + 미니맵 데이터

방 통신은 전부 `EventBus`(Dictionary 페이로드 + `emit_*` 래퍼)로만.
