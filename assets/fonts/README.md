# Fonts

Korean UI fonts copied from `../tailbound-godot/assets/fonts`.

Included:
- `NeoDunggeunmoPro-Regular.ttf` for default UI, HUD, buttons, counters, and short status text.
- `ChosunCentennial.ttf` for titles, speaker names, reward names, and section headers.
- `RIDIBatang.otf` for dialogue, narrative copy, subtitles, and longer body text.

License and attribution notices:
- `licenses/NeoDunggeunmoPro-NOTICE.txt`
- `licenses/ChosunCentennial-LICENSE.txt`
- `licenses/RIDIBatang-NOTICE.txt`

Keep the matching notice file with each bundled font when fonts are copied,
exported, or redistributed. If a font binary is replaced, update its notice from
the upstream source before committing the replacement.
