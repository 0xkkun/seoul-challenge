# 게임 종료·전환 처리 — 확인 모달 방식

> design-shotgun(2026-06-27) 결과 **A안(확인 모달)** 채택. 게임을 떠나거나 진행 상태가 바뀌는 **모든 이탈에 확인 다이얼로그 + 자동저장 + 페이드**.

## 시안 (확인 모달)

![확인 모달 시안](exit-flow-confirm.png)

```
┌──────── 게임 화면(가장자리 페이드) ───────────[ 저장됨 ✓ ]┐
│                                                          │
│          ┌────────────────────────────┐                 │
│          │   로비로 돌아갈까요?         │                 │
│          │   진행은 자동 저장됩니다      │                 │
│          │     [  예  ]   [ 아니오 ]    │                 │
│          └────────────────────────────┘                 │
│                                                          │
└──────────────────────────────────────────────────────────┘
```
- 중앙 모달 + 반투명 어두운 백드롭, **[예]=시안 #67e8f9 강조 / [아니오]=중립**
- 우상단 **`저장됨 ✓`** 인디케이터, 모든 전환은 **검게 페이드**
- 손실 경고가 있는 경우(런 포기)만 본문/버튼에 붉은 경고톤

## 적용 지점 (확인 정책)

| 전환 | 확인 | 문구(예) |
|---|---|---|
| 로비 → 낮 진입 | ❌(바로 페이드 진입) | — |
| 낮 → 로비 복귀 | ✅ | "로비로 돌아갈까요? 진행은 자동 저장됩니다" |
| 런 중 → 포기/로비 | ✅(손실 경고) | "런을 포기할까요? 이번 밤 보상은 사라지고 영구 재화는 유지됩니다" |
| 로비/게임 → 앱 종료 | ✅ | "게임을 종료할까요?" |
| 사망/클리어 → 귀환 | ❌(자동, 결과 화면 경유) | — (death_return_controller) |

## 구현 메모
- **재사용 `ConfirmModal`** 컴포넌트: `open(message, on_yes, on_no, danger=false)`
- **`SceneTransition`에 페이드 래퍼** 추가(현재는 하드 `change_scene_to_file`)
- **앱 종료/뒤로**: `Window`의 `WM_CLOSE_REQUEST`(데스크톱) + 모바일 뒤로(`ui_cancel`/Android back) → 확인 모달
- **자동저장 보장**: 이탈 직전 `SaveManager` 프로필 저장 후 전환, 완료 시 `저장됨 ✓`
- 영구 재화는 항상 유지(런 포기/사망에도) — 손실은 "이번 런 인게임 보상"뿐
